# SmartMenu Backend API — Postman Tests

This directory contains Postman collections for testing the SmartMenu Backend API.

## Test Coverage

- API functionality
- User registration
- User authentication and authorization
- Restaurant management

## How to Run

1. Import the required JSON collection into Postman.
2. Configure the API environment.
3. Set the required environment variables.
4. Run the collection using Postman Collection Runner.

## Notes

- Use test accounts for API testing.
- Do not store real passwords, JWT tokens or API secrets in this repository.
